# Project Instructions

## Project Overview

This repository is part of the Frontend AI Engineering track.

The goal is to build frontend projects using modern development practices and AI-assisted engineering workflows.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- GitHub
- Cursor

## Coding Conventions

- Use clear and descriptive names.
- Keep code simple and readable.
- Prefer small, focused functions.
- Avoid unnecessary dependencies.
- Keep files organised by responsibility.
- Do not commit secrets, API keys, or environment variables.

## AI Development Rules

- Explain significant changes before making them.
- Do not introduce unnecessary libraries.
- Preserve existing functionality when modifying code.
- Ask for clarification when requirements are unclear.
- Review changes before committing them.
- Follow the existing project structure and conventions.
## Project Rules

1. Use React and JavaScript for frontend components. Do not add unnecessary libraries.

2. Every form input must have an accessible label and clear validation messages for invalid input.

3. Form validation must check required fields and specific requirements before allowing submission.

4. Keep components simple and readable, and do not modify unrelated project files.

5. After implementing a feature, test the main user flows and fix any validation or accessibility issues found.
